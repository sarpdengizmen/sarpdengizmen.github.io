Isaac Game Box

"The Binding of Isaac: Four Souls" is a card game that ships in a modest box with many game components.This project is a purpose-built solution: an all-in-one storage container that converts into a fully functional game organiser for every component in the set.

The design constraint was that the box needed to serve two goals: as a closed container it should be able to hold all components securely and be carried around easily. Open, it becomes a game table — coins sorted by type, dice and tokens in their deicated slots. The transformation is part of the experience.

Structure and Mechanism

The box uses a hinged lid that locks when closed. The box is sized just right to fit the ratio of cards that is needed for the game, and also the two drawer style compartments for the dice, coins and tokens.

Every component is 3D printed, the box itself has a wood texture implemented into design which matches the rustic theme of the game.
