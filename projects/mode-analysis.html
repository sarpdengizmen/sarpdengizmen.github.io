Experimental Mode Analysis

Experimental modal analysis (EMA) is the process of identifying a structure's natural frequencies, damping ratios, and mode shapes directly from measured vibration data — without requiring a complete analytical model. This project applies EMA to a physical structure using impact hammer testing, frequency response function extraction, and time-domain system identification to produce a validated modal model.

The result is more than a set of numbers: modal parameters are the fingerprint of a structure's dynamic behaviour. They underpin resonance avoidance in design, structural health monitoring, and the correlation between finite element models and physical reality.

Frequency Response Function Extraction

The structure was excited with an instrumented impact hammer at multiple locations, and accelerometer responses were recorded at fixed measurement points. The FRFs (ratio of output acceleration to input force in the frequency domain) were computed via the H1 estimator, which minimises the effect of output noise. Coherence was monitored across all measurements to flag poor impact quality and ensure data integrity before any identification step.

Multiple impacts per location were averaged to improve the signal-to-noise ratio. The resulting FRF matrix reveals peaks at the structure's natural frequencies and phase information that encodes the mode shape contributions at each measurement point.

Ibrahim Time Domain (ITD) Method

Modal parameters were extracted using the Ibrahim Time Domain method — a classical algorithm that identifies poles of the structural system from free-decay response data. The method constructs a data matrix from sampled impulse responses and solves a generalised eigenvalue problem to extract complex eigenvalues (from which natural frequencies and damping ratios are derived) and eigenvectors (mode shapes).

Spurious computational modes were separated from physical modes using a stabilisation diagram: poles that remain stable across increasing model orders are accepted as physical; those that drift or appear erratically are rejected.

AutoMAC Validation

The Modal Assurance Criterion (MAC) was used to validate the identified mode shapes. The AutoMAC matrix — the MAC of each identified mode against all other identified modes — should ideally be an identity matrix: diagonal entries near 1.0 (each mode correlates perfectly with itself) and off-diagonal entries near 0 (modes are linearly independent). Elevated off-diagonal values indicate spatial aliasing or contamination between modes.

FE Model Correlation

The experimentally extracted natural frequencies and mode shapes were compared against a finite element model of the structure. Frequency discrepancies were used to guide model updating — adjusting material properties and boundary condition stiffness parameters to bring the FE model into agreement with physical measurements. The cross-MAC between experimental and FE modes confirms that the mode shapes are correctly paired before frequency comparisons are made.
