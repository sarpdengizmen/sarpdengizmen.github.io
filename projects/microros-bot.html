MicroROS Pick-and-Place Robot

This project is a fully autonomous pick-and-place robot built on a differential-drive platform. The robot's task: locate a red object anywhere on a flat workspace, navigate to it, pick it up with a two-DOF servo gripper, and deposit it at a fixed target location — all without human input after launch.

The challenge was integrating perception, real-time low-level control, and high-level task planning across three distinct computational tiers while keeping the total system latency low enough for reliable execution.

System Architecture

The system is partitioned into three tiers communicating over ROS 2:

  • ESP32 firmware (micro-ROS / FreeRTOS) — handles hard real-time motor PI control, quadrature encoder sampling at 1 kHz, and servo PWM generation. Communicates over UDP WiFi to the micro-ROS Agent running on a PC, bridging to the main DDS network.
  • PC Python nodes (ROS 2 / OpenCV) — run the vision pipeline: AprilTag corner detection for workspace calibration, homography-based coordinate transform, and HSV colour segmentation to locate the target object. Publishes pose estimates and issues velocity commands.
  • MATLAB / Simulink Stateflow — implements the high-level pick-and-place state machine. Sequentially transitions through: navigate-to-object → align → descend gripper → grip → navigate-to-target → release.

Workspace & Localisation

Four AprilTags (IDs 0–3) are taped at the corners of a 790 × 730 mm mat and define the metric coordinate frame via homography. The robot carries AprilTag ID 4 on top, giving the ceiling-mounted USB camera full 3-DOF pose estimation (x, y, heading) of the robot at all times. This architecture removes the need for onboard sensors for self-localisation — the world is instrumented, not the robot.

Low-Level Control

Each wheel is driven by a DRV8833 H-bridge module and controlled by a discrete-time PI controller running on the ESP32 at 100 Hz. Encoder counts from quadrature encoders (420 CPR) are used to close the velocity loop independently on each side. Differential steering is achieved by commanding different target velocities per wheel from the trajectory regulation node. The closed-loop response was tuned empirically to give sub-centimetre steady-state error on straight-line runs.

Gripper

The gripper uses two hobby servos — one for wrist rotation (orienting the gripper to approach the object from above) and one for the jaw. Both are driven by PWM directly from the ESP32. The jaw geometry was designed to self-centre small cylindrical objects and provides enough compliance to handle ±5 mm positional error without misgripping.
