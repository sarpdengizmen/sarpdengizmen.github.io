Desk Lamp

This desk lamp was borne from a desire to create a living structure. The result is a modular lighting structure built almost entirely from 3D-printed parts, where the user defines the form by arranging the light-bearing beams however they choose.

The concept draws from topogaphy, where the arrangement of beams create a special heightmap that defines the lamp's character. Stack them tightly and the lamp feels dense and sculptural; spread them wide and it becomes airy and minimal. Every configuration is unique.

Slicer Engineering: Translucent PETG

The beams are printed in translucent PETG, a material chosen specifically for its light-transmitting properties. To maximize the glow, the beams are printed with engineered infill patterns that optimize light diffusion. The result is a soft, even glow along the entire length of each beam.

IOT with Open-Source Firmware WLED

The lamp runs on WLED, an open-source firmware for addressable LED strips. An ESP8266/ESP32 microcontroller hosts a local web server and can connect to a home network, giving full control through any browser or the WLED mobile app. From there, the lamp supports hundreds of built-in effects — from solid static colour to reactive audio visualisation — and the user can save custom presets or schedule automations.

This makes the lamp genuinely "living": it changes character throughout the day. A slow, warm amber in the evening is a few taps away from a crisp white for focused work, or a cycling colour palette for ambiance. The open ecosystem also means the lamp can be integrated into home automation setups like Home Assistant with no additional hardware.
